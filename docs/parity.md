# Parity tables

A parity table lists the features of a kit crate next to the same feature in its reference library. Each row says whether kit has the feature, has part of it, or does not have it.

| Area | Reference | Table |
|---|---|---|
| arrays | NumPy | [arraykit](parity/arraykit.md) |
| data frames | pandas | [frame](parity/frame.md) |
| statistics | SciPy | [scikit](parity/scikit.md) |
| signal | SciPy | [scikit](parity/scikit.md) |
| plots | Matplotlib | [others](parity/others.md) |
| agents | LangChain and LangGraph | [others](parity/others.md) |
| classic machine learning | scikit-learn | [others](parity/others.md) |
| deep learning | PyTorch | [others](parity/others.md) |

Each `missing` row names a later issue. The issue list of the repository tracks that work.
