# Security policy

## Supported versions

Only the latest release on `main` gets security fixes.

## Report a vulnerability

Use GitHub private vulnerability reporting. Open the repository's Security tab and click "Report a vulnerability".

Do not open a public issue for a security problem.

## What to include

- The affected crate and its version.
- Steps to reproduce the problem.
- The impact: what an attacker can do.

## Response

We acknowledge a report within 7 days. We fix the problem or answer the report within 90 days.
